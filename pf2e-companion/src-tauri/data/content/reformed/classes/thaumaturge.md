# Thaumaturge — the hardest Reformed reskin (be honest)

In the Catholic and Orthodox lenses the Thaumaturge is the **elegant
win**: nine implements map 1:1 to relic categories, zero rules change.
**That win evaporates here.** Reformed theology rejects relic-veneration
explicitly: Calvin's *Treatise on Relics* (1543) is the canonical
polemic, cataloguing the spurious relics of Europe and arguing that
relic-piety is idolatrous. Heidelberg Q.96-98 forbids visual images
of God, and the Reformed regulative principle of worship
(Westminster XXI) limits liturgical practice to what Scripture
positively warrants.

This is the place where the Reformed lens **costs the most
mechanically**. The honest options:

## A. Cut the Thaumaturge from the playable class set

Strictest reading. If your table cannot abstract relic-power into
something Reformed-coherent, simply do not allow the Thaumaturge.
The Reformed lens **does not need** the Thaumaturge to function;
its absence is theologically clean.

## B. Reframe implements as covenant-tokens

The middle path, and the recommended default for this pack. The
Thaumaturge's implement is **not a venerated object channeling saintly
power** — it is a **covenant-token**: a sign-of-the-covenant that the
character carries, whose effect is **always credited to the Word and
the Spirit, never to the object itself**. The implement is *Word-as-
implement*, not *saint-as-implement*.

### Reformed implement reskin table

| PF2e implement | Reformed covenant-token reskin | Source |
|---|---|---|
| Tome | **The Bible itself** — primary Reformed implement | Heb 4:12; Westminster I |
| Lantern | "Thy word is a lamp unto my feet" | Ps 119:105 |
| Weapon | The sword of the Spirit (always paired with Tome) | Eph 6:17 |
| Wand | Moses's staff / shepherd's crook (cf. [[reformed:moses]]) | Ex 4:2; Ps 23 |
| Regalia | The Geneva gown / pulpit robe (vocational, not sacerdotal) | (Reformed practice) |
| Chalice | **Memorial communion-cup** (Zwinglian/Calvinist memorial reading, NOT Real Presence) | 1 Cor 11:25 |
| Bell | Sabbath-summons / kirk bell | (Reformed practice) |
| Mirror | Pauline glass — sanctification as progressive seeing | 1 Cor 13:12; 2 Cor 3:18 |
| Amulet | **Hardest fit — recommend cut.** Phylactery / scapular reading is too close to Heidelberg Q.96-98 idolatry. | — |

### Why this works (and where it strains)

The covenant-token framing **honestly resolves** Tome / Lantern /
Weapon / Wand / Mirror — these are all already Word-and-Spirit
imagery in Scripture. Chalice is **strained** but Zwinglian-memorial
language carries it. Regalia is vocational. Amulet is the place
where the lens just doesn't fit; recommend cutting it.

## C. NPC-only, foreign-tradition flavor

Run Thaumaturges in your world as **non-Reformed NPCs** — Catholic
relic-pilgrims, Orthodox icon-bearers, syncretic folk-religious
characters. PCs cannot take the class. This is a campaign-setting
solution that lets the class exist without endorsing it.

## DragonRaid trap (don't)

**Do not require the player to recite real scripture for implements
to function.** The mechanical surface is RAW; the flavor frame is
covenant-token. A Reformed table is *especially* prone to want to
mechanize Bible-citation because the Reformed canonical instrument
*is* the Word — resist this. The implement works because the GM
adjudicates PF2e rules, not because the player passes a catechism
check.
