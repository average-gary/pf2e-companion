# Thaumaturge — the pilgrim of relics

The Thaumaturge's nine implements map **1:1** to Christian relic
categories that already exist in the historical tradition. **Zero rules
change.** This is the "elegant win" of the reskin set.

## Implement reskin table

| PF2e implement | Lewisian relic | Source resonance |
|---|---|---|
| Chalice | Eucharistic chalice / Holy Grail tradition | 1 Cor 11:25 |
| Regalia | Episcopal vestments / Aaronic priestly garments | Exodus 28; Lev 8 |
| Tome | The Bible itself, or a saint's *vita* | Heb 4:12 |
| Lantern | Paschal candle / "thy word is a lamp" | Ps 119:105 |
| Weapon | St Michael's spear / the Holy Lance / Aaron's staff | Exodus 7:10; Rev 12 |
| Mirror | Pauline glass / icon-as-window | 1 Cor 13:12 |
| Amulet | Reliquary pendant / scapular / phylactery | Num 15:38; Catholic devotion |
| Bell | Liturgical bell / sanctus bell | Exodus 28:33-35 |
| Wand | Staff of Moses / shepherd's crook | Ex 4:2; Ps 23 |

## Honest gotchas

- **The Thaumaturge is a pilgrim, not a sorcerer.** The class fantasy is
  exactly right: a saint who wields sacred objects, drawing on their
  consecrated power without claiming it as her own. This is the inverse
  of Simon Magus's transactional purchase (Acts 8). Frame the implement
  as something *given* — found on pilgrimage, inherited from a
  predecessor, granted by a vision.
- **No `pharmakeia` problem here.** The Thaumaturge's effects are sign-
  bearing, not drug-mediated; the implement is a token of faith, not a
  technique. Aquinas's q.96 a.4 (amulet rules — canonical Scripture
  only, no characters except the Cross) is the relevant guidance for
  flavor, though we don't enforce it mechanically.
